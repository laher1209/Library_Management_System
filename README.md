# Library Management System 📚

A simple Python project that manages a library using Object-Oriented Programming (OOP).

## Features

* Add books to the library.
* Display the total number of books.
* Display the names of all books available in the library.

## Technologies Used

* Python
* Classes and Objects (OOP)
* Lists
* Methods

## Books Added in This Project

* Harry Potter
* The Alchemist
* Rich Dad Poor Dad
* Atomic Habits
* Wings of Fire

## Project Structure

* `Library` class
* `addBook()` method to add books
* `showInfo()` method to display library information

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python library_management_system.py
```

## Example Output

```text
The Library has 5 books, and the books are:
Harry Potter
The Alchemist
Rich Dad Poor Dad
Atomic Habits
Wings of Fire
```
